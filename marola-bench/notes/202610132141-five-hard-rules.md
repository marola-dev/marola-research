# Seven hard rules

1. Apache Pekko, Scala 3.
2. GCP, developed with Claude Code, with an SDD framework.
3. Infrastructure as code with Besom.
4. It lives in `marola-research/marola-bench`.
5. The deployment of the cluster is cheap and reliable.
6. All rights reserved, the credit is the author's, and whoever uses it cites it.
7. Ponytail 5 is adopted as the coding assistant, a Claude Code plugin.

There were five when this note was made; the sixth came later the same day, and the seventh on
14 October 2026, in the owner's words: "Ponytail 5 will be adopted as Coding Assistant (Claude
Code Plugin)". The file keeps its first name, as a note's name does.

Five of the seven change the accepted design, MIP-0091: it has Kyo, zero cloud spend, modules in
marola-app, a cycle on GitHub Actions and a public chain under CC BY 4.0. The rules are the later word. A MIP must say how the
two meet: [[202610132147-zero-spend-meets-a-paid-cloud]].

Rule 7 changes nothing in MIP-0091, which names no plugin. It does not name rule 2's SDD
framework either: Ponytail decides how small a change is, not what it is for.

Rule 2 does not name the framework. The candidates are listed in the pull request that added the
paper (marola-dev/marola-research#2).
